کوتاه‌کننده لینک موکو

یک کوتاه‌کننده لینک سبک و سریع نوشته‌شده با PHP خالص و MySQL. این پروژه بدون هیچ فریم‌ورکی توسعه داده شده و لینک‌های بلند را به لینک‌های کوتاه ۷ حرفی تبدیل می‌کند.
