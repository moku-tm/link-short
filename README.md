# کوتاه‌کننده لینک موکو

یک کوتاه‌کننده لینک سبک و سریع نوشته‌شده با PHP خالص و MySQL. این پروژه بدون هیچ فریم‌ورکی توسعه داده شده و لینک‌های بلند را به لینک‌های کوتاه ۷ حرفی تبدیل می‌کند.

## ویژگی‌ها

**همه چیزی که برای کوتاه کردن لینک نیاز دارید**

| | ویژگی | توضیح |
|---|---|---|
| ⚡ | **کوتاه‌سازی آنی** | با زدن Enter یا کلیک دکمه، لینک فوراً کوتاه می‌شود |
| 🔄 | **ریدایرکت سریع** | بدون صفحه میانی، مستقیم به آدرس اصلی ریدایرکت می‌شود |
| 🔌 | **API ساده** | دریافت اطلاعات لینک با یک GET درخواست ساده |
| 🎨 | **دارک و لایت مود** | دو تم زیبا با قابلیت سوئیچ لحظه‌ای |
| 🛡️ | **امنیت کامل** | CSRF, XSS, SQL Injection و Rate Limiting |
| 📱 | **کاملاً ریسپانسیو** | طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ |

## API

**دریافت اطلاعات لینک کوتاه از طریق API**

### 🔌 مستندات API

بدون نیاز به ثبت‌نام یا کلید API. حداکثر ۳۰ درخواست در هر ۳۰ ثانیه.

**`GET /api?short={کد-۷-حرفی}`**

```json
{
    "status": "success",
    "data": {
        "short_url": "https://link.emadcoder.ir/Ab3xY9z",
        "original_url": "https://example.com/very-long-url",
        "clicks": 12,
        "created_at": "2024-01-15 10:30:00"
    }
}
```

## نصب و راه‌اندازی

**در ۳ مرحله ساده سیستم را راه‌اندازی کنید**

| مرحله | عنوان | توضیح |
|---|---|---|
| **1** | **آپلود فایل‌ها** | فایل‌ها را در روت هاست آپلود کنید و دسترسی پوشه tmp را ۷۵۵ قرار دهید |
| **2** | **اجرای اینستالر** | به آدرس `sitedomain/installer/` بروید و اطلاعات را وارد کنید |
| **3** | **تمام!** | سیستم آماده است. شروع به کوتاه کردن لینک‌ها کنید |
